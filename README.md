# 사이 / SAI

A small interactive universe made of dots and lines, built with vanilla HTML, CSS and Canvas 2D.

Open `index.html` directly, or deploy on Vercel using the Other framework preset. No dependencies or build step.

- Move to repel, hold to attract, click to create a ripple.
- Switch between Drift, Orbit and Vortex.
- Adjust energy, pause with Space, regenerate, or save a PNG.
- Touch and keyboard support. Reduced-motion preferences start paused.
